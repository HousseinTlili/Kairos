# M9 — Voice

Implementation spec. Read `CLAUDE.md` and `docs/milestones/M8.md` (the quick box) first.

**Status (2026-10-25):** §2 and §4 approved by the product owner; being built. Branch `m9/voice`, which starts from `m8/always-there`. Checks marked
**(on the PC)** are collected in `docs/TESTING.md`.

---

## 1. Goal and scope

- **Speak instead of typing**, push-to-talk: hold a key (or the mic button), speak, let go; the
  words appear in the chat box and are sent. Nothing listens at any other time.
- **Speech to text runs on the PC** with Whisper (whisper.cpp): offline, no audio leaves the PC,
  English, French and Arabic (and mixed) from one multilingual model.
- **Answers read aloud**, on request: a speaker button on each answer, an optional "Read answers
  aloud" switch, and "Read it to me" on the welcome-back briefing. Windows's own voices, through
  the webview's `speechSynthesis`; no new dependency.

**Out of scope:** a wake word ("Kairos…", always listening). The product owner chose push-to-talk
on 2026-10-25; a wake word can come later on top of the same speech-to-text. Hermes's own speech
endpoints are not used: they are on its dashboard server, which Kairos's contracts
(`ARCHITECTURE.md` §3) don't cover, and the API server has none.

## 2. Decisions

- **D-022 — Speech to text is local Whisper in the app, push-to-talk only — Accepted** (with §4,
  on 2026-10-25). Chosen by
  the product owner on 2026-10-25 (local Whisper; push-to-talk) over Windows's online speech
  recognition and Hermes's dashboard server. The app records with the webview
  (`getUserMedia`), converts to 16 kHz mono in the webview (`OfflineAudioContext`), and a Tauri
  command transcribes it with `whisper-rs` on a background thread. The transcript is ordinary
  chat text: it goes through Hermes and the Kairos rules like anything typed. Audio is kept in
  memory only and never written to disk. The model is downloaded once, when the user presses
  **Download**, from the whisper.cpp project's Hugging Face page, and checked against its SHA-256
  before use.

## 3. How it fits together

```
hold Ctrl+Alt+J ──► quick box opens, "Listening…"   (or: mic button in any chat box)
      │                 webview records the mic
release ──────────► 16 kHz mono samples ──► invoke("transcribe") ──► whisper-rs (CPU, AVX2)
                                                              │
                         text in the chat box ◄───────────────┘ ──► sent like typed text
answer arrives ──► (speaker button / "Read answers aloud") ──► speechSynthesis, Windows voice
```

- **Models** live in `%APPDATA%\kairos\models\`. Choice in Settings ▸ Voice:

  | Model | File | Size | SHA-256 (from the Hugging Face file list) |
  |---|---|---|---|
  | Small (default; best for French and Arabic) | `ggml-small-q5_1.bin` | 190 MB | `ae85e4a935d7a567bd102fe55afc16bb595bdb618e11b2fc7591bc08120411bb` |
  | Base (faster, weaker on Arabic) | `ggml-base-q5_1.bin` | 60 MB | `422f1ae452ade6f30a004d7e5c6a43195e4433bc370bf23fac9cc591f01a8898` |

  Download writes to `<name>.part`, checks the hash, then renames, so a broken download is never
  loaded. The model is loaded on first use and unloaded after 10 minutes without speech (it holds
  a few hundred MB of memory).
- **Language:** detected per recording by default; Settings ▸ Voice can fix it (English, French,
  Arabic). The detected language is shown next to the transcript.
- **Limits:** a recording stops at 60 s. Silence-only recordings (very low energy) are dropped
  without calling Whisper. Whisper's known habit of inventing text on silence ("Thank you.") is
  filtered by that energy check.
- **Push-to-talk key:** `Ctrl+Alt+J` by default, changeable in Settings ▸ Voice, registered with
  the global-shortcut plugin M8 already uses (pressed and released states). Holding it opens the
  quick box in listening mode; releasing it transcribes and sends. In any chat box the mic button
  does the same with click-to-start, click-to-stop. Esc cancels a recording.
- **Speech out:** the voice is chosen per answer from its language (Windows voices for that
  language, else the default). This PC has only English voices (David, Mark, Zira); French and
  Arabic voices are added in Windows Settings ▸ Time & language ▸ Speech, and Settings ▸ Voice
  says so when one is missing. Speaking stops on Esc, on a new request, or on the stop button.
  Code blocks are not read aloud ("code block skipped").
- **Microphone permission:** WebView2 asks the first time; Windows Settings ▸ Privacy ▸ Microphone
  must allow desktop apps. Settings ▸ Voice has a "Test microphone" level meter.
- **Briefing:** the M5 briefing card gets "Read it to me". The briefing is never read aloud on its
  own.

## 4. Dependencies (approved by the product owner on 2026-10-25)

| What | Why |
|---|---|
| `whisper-rs = "=0.16.0"` (Unlicense; whisper.cpp, MIT) | Local speech to text. Released 2026-03-12. CPU only (no CUDA feature): the probe build on this PC uses AVX2. |
| `sha2` (already in `Cargo.lock` through Tauri, `=0.10.9`) | Checking the downloaded model. |

**Build prerequisites (new):** whisper.cpp is C++ built with CMake, and its bindings need libclang.
Both are already on this PC: CMake inside VS Build Tools 2022, libclang in `C:\Program Files\LLVM`.
Probe on 2026-10-25: `whisper-rs 0.16.0` builds in 24–35 s (release) with CMake on `PATH` and
`LIBCLANG_PATH` set, from a normal shell; it fails with "No CMAKE_CXX_COMPILER" when the build
folder's path is too long (a 260-character limit inside MSBuild), which the repo's own `target\`
is not. Proposal: `app/src-tauri/.cargo/config.toml` sets `CMAKE` and `LIBCLANG_PATH` to those
standard locations unless they are already set, and CLAUDE.md's command table says so.

No new JavaScript packages.

## 5. Steps

### Step 1 — Spec
This file, D-022 (Proposed), ROADMAP, `docs/TESTING.md`. **Check:** the product owner approves §2
and §4.

### Step 2 — Model download and Settings ▸ Voice
Rust `voice/models.rs`: list, download with progress events, hash check, delete (asks first).
**Check:** Rust tests: a wrong hash leaves no model and no `.part`; an interrupted download is
resumed from scratch; the list reports Missing / Downloading / Ready. **(On the PC)** download
Small; Settings shows Ready.

### Step 3 — Transcription
Rust `voice/stt.rs`: `transcribe(samples, language)` on a blocking thread, lazy load, idle unload,
silence check. **Check:** Rust tests for the silence check and the sample checks (length, rate);
an ignored test transcribes a short fixture WAV (synthetic speech, no personal data) with the
Base model. **(On the PC)** the fixture transcribes in under 2 s.

### Step 4 — Recording and the mic button
`app/src/features/voice/`: recorder (getUserMedia → 16 kHz mono), mic button in the chat box and
the quick box, level meter, 60 s limit, Esc cancels. **Check:** TS tests for the resampler, the
60 s cut and the states (idle, listening, transcribing, error). **(On the PC)** speak an English,
a French and an Arabic sentence; each appears correctly and is sent.

### Step 5 — Push-to-talk hotkey
Hold `Ctrl+Alt+J` over any app. **Check:** Rust tests for the pressed/released handling; TS
tests. **(On the PC)** hold, speak, release: the quick box answers; a refused hotkey is reported
in Settings.

### Step 6 — Speech out
Speaker button per answer, "Read answers aloud", "Read it to me" on the briefing, voice per
language, code blocks skipped, Esc stops. **Check:** TS tests for the text prepared for speech
(code blocks, links, Markdown) and the voice choice. **(On the PC)** an English answer is read
aloud; a French one uses a French voice once one is installed.

### Step 7 — Acceptance (product owner, on the PC)
`docs/milestones/M9-acceptance.md`.

## 6. Definition of done

- Push-to-talk from any app and the mic button work in English, French and Arabic, offline.
- No audio is written to disk or sent anywhere; the transcript is the only thing that leaves the
  speech code, as chat text under the Kairos rules.
- Answers and the briefing are read aloud only when asked.
- All tests and lints pass on Windows; the product owner has run the acceptance checklist.

## 7. Ask the product owner, don't guess

- A different default push-to-talk key than `Ctrl+Alt+J`.
- GPU transcription (CUDA, for the RTX 4060): faster, but needs the CUDA toolkit to build and a
  second build feature. Not in M9 unless asked.
- A wake word.

# M10 — Persona and avatar

Implementation spec. Read `CLAUDE.md` first.

**Status (2026-10-26):** Part 1 (persona) being built on `m10/persona`, which starts from
`m9/voice`. Part 2 (the animated avatar) comes after the memory milestone. Checks marked
**(on the PC)** are collected in `docs/TESTING.md`.

---

## 1. Goal and scope

**Part 1 — persona.** Kairos has a character of its own instead of Hermes's default voice. Chosen
by the product owner on 2026-10-26:

- **Tone:** JARVIS-like: calm, precise, quietly witty, a little formal; anticipates what is needed;
  never fawning.
- **Address:** calls the product owner **"Master"**.
- **Language:** always answers in **English**, whatever language it is spoken or written to (the
  words it hears are still transcribed in their own language, M9).

**Part 2 — avatar (later).** The animated avatar driven by run events (`idle`, `listening`,
`thinking`, `speaking`); its own spec section when it is next.

**Out of scope:** memory (the next milestone: a "What Kairos remembers" page and a trial of one
Hermes memory provider); Graphify (a possible code-project skill later, not memory).

## 2. Decisions

- **D-023 — The persona is Hermes's own `SOUL.md`, edited from the app — Accepted** (the product
  owner chose "persona now" on 2026-10-26). Hermes reads `<HERMES_HOME>\SOUL.md` into the system
  prompt each time it builds one [source: `agent/prompt_builder.py` `load_soul_md`], so Kairos
  uses that contract and nothing else: no Hermes code is touched and no prompt is injected per
  turn. The file belongs to the user's Hermes profile, so Kairos writes it **only when the user
  presses Save** in Settings ▸ Persona; before its first write it copies the file as it was to
  `%APPDATA%\kairos\backups\SOUL.md.before-kairos` (once), and "Restore the original" puts that
  copy back. Writes are atomic (temporary file, then rename). A persona applies to conversations
  started after it is saved; Hermes keeps an open conversation's system prompt (its prompt cache).

## 3. The persona text

The starter text is in `app/src-tauri/src/persona.rs` (`KAIROS_PERSONA`). It keeps Hermes's own
rules for directness (no filler, length matched to the ask, say plainly when unsure) and adds:
the name and character, "Master", English only, short spoken-friendly replies when the request
sounds spoken, and what Kairos is (a desktop assistant whose actions pass the Kairos rules, which it
must respect and never try to get around). It is an ordinary text file: the product owner can
change anything on the page.

## 4. Settings ▸ Persona

- The current `SOUL.md` in an editor, with "Kairos persona" / "Hermes default" / "Your own text"
  shown above it.
- **Use the Kairos persona** fills the editor with the starter text (nothing is written yet).
- **Save** writes the file (backup first, the first time).
- **Restore the original** puts the backed-up file back (asks first).
- A note: "Applies to new conversations."

## 6. Ask the product owner, don't guess
